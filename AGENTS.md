# AGENTS.md

Guidance for AI coding agents working in this repository.

## What this is

React + Vite dashboard for Magic Formula stock screening on NSE stocks. Python pipeline scrapes Moneycontrol, ranks stocks, writes `public/data/latest.json`. Two Vercel Edge functions serve AI analysis and Yahoo Finance context. Deploys: GitHub Actions → GitHub Pages (static mirror) + Vercel (primary, hosts the API).

## Repo map

```
src/services/ai.ts        client: prompt building, cache, calls POST /api/ai; NO keys here
src/App.tsx               all UI (table, modal, verdict display)
api/ai.ts                 edge fn: Gemini→Groq→HF fallback chain, server-side keys
api/stock-context.ts      edge fn: Yahoo price/PE/news, 5-min TTL cache
data_pipeline/
  build_dashboard_data.py entrypoint; ranking math; success-rate gate
  magic_formula/         scraper package (client, parsers, fetcher)
  tests/                 pytest + HTML fixtures captured from live pages
public/data/latest.json   committed snapshot; regenerated by pipeline
.github/workflows/deploy-pages.yml   cron 22:30 UTC (04:00 IST) + push trigger
```

## Commands

```bash
npm ci && npm run lint && npm run build   # frontend checks
npm run test:data                          # python tests (pytest, needs requirements-dev.txt)
npm run data:build                         # rank from cache/seed, no network
MF_SYMBOL_LIMIT=20 python data_pipeline/build_dashboard_data.py --scrape  # small live scrape test
```

Full scrape is ~2000 symbols × 4 requests at 3 workers — minutes long; never run it casually.

## Conventions

- TypeScript strict; eslint must pass (`npm run lint`); no unused exports.
- Python: no linter configured yet — keep style consistent with existing files.
- No comments unless the code is genuinely non-obvious.
- Never put API keys anywhere under `src/` or any `VITE_*` variable. Keys belong in `api/*.ts` reading `process.env`.
- Parser changes must keep `tests/test_parsers.py` green. If Moneycontrol legitimately changed their HTML, re-capture fixtures into `data_pipeline/tests/fixtures/` and update assertions.

## Gotchas (learned the hard way)

1. **Moneycontrol HTML drifts constantly.** The ratios page now serves data inside `__NEXT_DATA__` JSON with short internal codes (`SC_TTM`, `BVCONS`, `PECONS`), not tables. Parsers whitelist fields; do not revert to scraping all `<tr>` rows — peer-name columns leak in and pollute batches.
2. **Groq's qwen model emits `<think>` blocks** — `stripThinking()` in `api/ai.ts` handles it. Keep it when changing models.
3. **GitHub Pages has no `/api/*`** — the Pages build sets `VITE_API_BASE_URL=https://mf-dashboard-three.vercel.app` so static users still get AI/context via Vercel. CORS allowlist in both edge fns must include the Pages origin.
4. **Scrape gate:** `scrape_master_data` fails the run below `MF_MIN_SUCCESS_RATE` (default 0.6). If CI fails there, check whether Moneycontrol is blocking (403/503) before assuming a code bug.
5. **Enterprise Value is a market-cap proxy** and ROC uses book equity — documented in README + shipped in `latest.json` `valuation` metadata. Don't "fix" one without the other.
6. **Vercel env vars needed:** `GOOGLE_API_KEY`, `GROQ_API_KEY`, `HUGGINGFACE_API_KEY` (legacy `VITE_` names also read). Without them `/api/ai` returns auth errors.
7. **Cron vs push:** both do full scrapes. A push right before the cron window causes two runs; `concurrency.group: pages` serializes deploys but not scrapes.
8. **`nse_stocks.csv` universe is frozen** — new NSE listings require manually refreshing that file.
